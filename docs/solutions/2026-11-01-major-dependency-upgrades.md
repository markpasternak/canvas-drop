## Versions and compatibility

The separate major round follows compatible maintenance PR #151. Node 26.13.0 is the supported LTS runtime, pinned in `.nvmrc`, CI and both container stages, with `^26.13.0` engines and Node types 26.6.6. Node 26 does not bundle Corepack: install pnpm 12.16.1 explicitly. Other migrated lines are better-sqlite3 13.0.3 (types 9.6.0), Vitest 5.0.5, jsdom 30.1.3, jest-dom 7.0.1, react-dropzone 20.1.4 and Mermaid 12.2.0. The plan links primary migration sources.

Vitest 5 and jest-dom 7 require explicit peers, so root Vite 8.3.5 and dashboard `@testing-library/dom` 10.4.2 are declared. Existing matchers typecheck without a compatibility shim. No assertion, isolation rule or repository timeout was weakened. The sole peer warning is the pre-existing `@hono/node-ws` 1.3.1 range for node-server 1.x against installed 2.1.5; existing WebSocket coverage remains green.

The final registry check reports only Geist Mono 5.2.8 behind latest 5.3.0. That intentional exact pin protects immutable served font URLs and belongs in a separate font/cache migration. `pnpm audit --json` reports zero advisories at every severity, including the former low KaTeX finding.

## Behavior changes that needed adaptation

- New dropzone/file-selector versions prefix loose paths with `./`. Strip that prefix before common wrapper-directory detection so a top-level HTML file plus multiple directories retains correct paths. A real drop event regression exercises the library rather than mocking path normalization alone.
- Newer dropzone enables file pastes. Both upload surfaces explicitly set `noPaste: true`, preserving ordinary clipboard handling and preventing an editor paste from silently uploading files. New regressions cover creation and editor surfaces.
- Mermaid 12 changes layout defaults. Pin dagre/classic, restore content-sized flowchart nodes (`minNodeWidth: 0`) and the previous wrapping width (200). A labeled Draft self-loop still collided with the publish label in a real browser; represent editing as an explicit return step so the layout reserves space for its label. Strict security, local assets, token-derived colors and CSP remain intact.
- The full Mermaid bundle increases from 3,458,403 raw / 963,466 gzip bytes to 5,262,131 raw / 1,505,959 gzip bytes. It remains deferred and loaded only by the two diagram pages. Retaining all supported renderer features is deliberate; no remote runtime is introduced. Mermaid 12's ES2024 runtime requirements remain relevant (Safari 17.4+); an esbuild syntax target is not an API polyfill. Browser evidence here is Chromium, not a claim of a full WebKit matrix.
- SQLite 13 ships N-API prebuilds and no installation script. Remove the container's now-unnecessary compiler setup and correct operator docs. Fresh-image verification is authoritative for Linux native packaging.
- The new container drill exposed a pre-existing `.dockerignore` exclusion of public docs/landing assets. Keep the precise runtime assets, OG card and skill files in the image and assert the actual public routes from its compiled non-root server.
